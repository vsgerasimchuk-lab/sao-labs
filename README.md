# Структуры и алгоритмы обработки данных — лабораторные

## ЛР 1 (вариант 7)

Анализ временной сложности элементарных алгоритмов:
- `array_sum`, `array_max` — O(n)
- `count_equal_pairs` — O(n²)
- `binary_pow` — O(log n)

### Запуск

Из папки курсового репозитория (где лежит `data/generated`):
```
python labS1.py --variant 7
```

### Файлы

- `labS1.py` — реализация 4 алгоритмов и бенчмарк
- `report.md` — отчёт с оценками, графиками и выводами
- `lab01_loglog.png` — log-log график для степенных алгоритмов
- `lab01_binary_pow.png` — график t(log₂ n) для бинарного возведения
